# **Maersk AI TTT Enablement Program**

Building internal capability for AI-Augmented Development and Agentic AI Application Building

# **1\. Objective and Program Outcome**

Maersk aims to build internal Subject Matter Experts (SMEs) who can independently deliver structured AI engineering programs to other employees. This engagement therefore combines reusable technical courseware, trainer-enablement skills, and observed teaching practice \- creating a repeatable internal capability rather than a one-time training intervention.

| Two blended programs: AI-Augmented Software Development and Agentic AI Application Building. |
| :---- |

# **2\. What Maersk Receives**

## **A. Module Teaching Packs**

For each technical module, Maersk receives four standardized assets:

| Asset | Purpose |
| :---- | :---- |
| Instructor Slides | Concepts, demonstrations, workflows, cues and discussion points. |
| Standard Lab | Repeatable hands-on exercise with setup, tasks, expected output and solution. |
| Module Assessment | Knowledge checks and applied tasks aligned to module outcomes. |
| Capstone Integration | A module checkpoint that extends the common reference project. |

## **B. Standard Capstone / Reference Projects**

* Capstone design: the final problem statement will be co-designed with Maersk domain SMEs so it reflects a realistic Maersk context while remaining broad and intuitive enough for participants from different technical and business backgrounds to understand.  
* A single standard reference codebase will anchor the learning experience. All module labs will extend, inspect or improve this same codebase, so participants and future trainers progressively build familiarity instead of repeatedly learning unrelated examples.  
* Track A uses the codebase across context engineering, coding, testing, PR, CI, security and review. Track B extends an enterprise agentic application across LLM integration, tools/MCP, enterprise data, guardrails, tracing and evaluation. Repositories include starting code, completed implementation, module checkpoints, lab solutions, synthetic data, setup instructions and troubleshooting guidance.

# **3\. Trainer Enablement \- How to Teach the Program**

Selected Maersk SMEs are trained not only on the technical content, but also on how to deliver it effectively. Four trainer modules are proposed:

| 1\. Teach, Demo & Prepare | Explain \-\> demonstrate \-\> practice \-\> validate; demo preparation, instructor tips, handling demo failures. |
| :---- | :---- |
| 2\. Lab Handling & Troubleshooting | Facilitate labs, diagnose setup/code issues, support mixed speeds, guide without giving away answers. |
| 3\. Questions & Classroom Management | Handle technical questions, unknown answers, advanced/beginner participants, pacing and participation. |
| 4\. Full-Class Preparation & Reflection | Pre-course readiness, environment checks, pace monitoring, feedback review and post-course improvement. |

# **4\. Teaching Practice, Feedback and Readiness**

* Practice Round 1: each SME teaches an assigned section; delivery is observed, rated and followed by structured feedback and course correction.  
* Practice Round 2: each SME teaches again after incorporating feedback, enabling re-evaluation of improvement and delivery readiness.  
* Evaluation dimensions: technical accuracy, concept explanation, demonstration quality, lab facilitation, question handling, communication, time management and learner engagement.  
* Readiness outcome: Ready to Deliver Independently / Ready with Initial Support / Requires Additional Practice.

# **5\. Delivery Structure and Scheduling Flexibility**

The exact split of trainer-enablement and teaching-practice sessions should be finalized around the availability of Maersk SMEs. The activities may run as dedicated full-day blocks, or be distributed across alternate days in approximately 1-2 hour sessions. The distributed model can work particularly well for TTT because SMEs can prepare, practice and incorporate feedback between sessions while continuing their regular responsibilities.

# **6\. Final Deliverable**

| Outcome: Two reusable technical curricula, approximately 10 Module Teaching Packs, Maersk-SME-informed capstone problem statements and shared reference codebases, trainer-enablement content, evaluation framework, two rounds of observed practice, and an internally prepared group of Maersk SMEs able to scale the programs. |
| :---- |
