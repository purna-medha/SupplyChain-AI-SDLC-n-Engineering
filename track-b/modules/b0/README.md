# B0 · Python foundations for supply-chain AI applications

Use B0 before B1 when participants need the Python subset used in Track B.
The language path covers values, records, collections, control flow, functions,
exceptions, objects, imports, dates, JSON and configuration. Follow-on examples
introduce SQLite, decorators, async calls, a local API, logging and tests.

- [Incremental Markdown slides](../../slides-md/b0-python-foundations.md)
- [Runnable snippets, expected observations and learner changes](../../snippets/b0/README.md)
- [Gamma-ready slide text](../../slides-gamma/b0-python-foundations.txt)

The numbered snippets use standard-library Python and need no model access.
All operational data and transport quotes are synthetic. The optional FastAPI
service has its own dependency command and uses no capstone storage.

This module adapts the BFSI M0 teaching progression to supply-chain examples.
It prepares learners to read B1–B3 without duplicating B1's model-access topics.
No new delivery-time allocation is assumed.
