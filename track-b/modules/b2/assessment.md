# B2 assessment

1. What is the difference between defining `get_status`, advertising its JSON schema, and executing it?
2. A model returns a valid JSON request for `delete_container`. Why must the host reject it even if JSON parsing succeeds?
3. What two message types must be preserved when returning a tool observation, and how is the observation linked to its request?
4. The completed guided ETA lab prints one observation, four rejections and `reads 1`. What does this prove, and what does it not prove about model quality?
5. In the MCP pair, which component publishes the function, which discovers it, and does discovery itself authorize execution?

## Evidence and scoring

Answer in your own words and cite a message field or execution boundary where relevant. Each question is worth 2 points, for 10 total. Award one point for the correct distinction or prediction and one for its causal explanation. A correct label without reasoning earns at most one point. Question-specific criteria and reasoned answers are in the instructor guide. Use the scores diagnostically: revisit host admission and correlation where explanations are missing.
