# B2 · Core teaching examples

The [five-file sequence](../../snippets/b2/README.md) implements four teaching steps: ordinary function → SDK tool-using agent → LlamaIndex comparison → MCP server/client pair.

Use the same synthetic status capability throughout. The no-tool Agent wrapper is an optional reference; a second MCP client is a reuse demonstration or lab extension. The earlier manual-dispatch examples are outside the core path.

The [slides](../../slides-md/b2-tools-and-mcp.md) explain the concepts before code and include the separate one-hour lab outline.
