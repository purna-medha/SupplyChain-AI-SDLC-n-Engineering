# Track B · Runnable teaching examples

Use the [course map](../README.md) for module order, status and snippet-guide links.

Each numbered file is a complete worked example. Run it, change one input and inspect the result. B2's MCP server/client pair runs in two terminals.

- **B0:** standard-library Python; the optional API has separate dependencies.
- **B1–B5:** follow [shared setup](../SETUP.md), then use `uv run python snippets/...`.
- **B6:** follow [its environment setup](../SETUP.md#later-modules), then use `python snippets/...`.

Each module README lists its file sequence and a learner variation. Optional additions live in `extensions/`; supporting older examples live in `reference/`.

Model examples need actual access. Service failures are not replaced by prepared replies. [Notebooks](../notebooks/README.md) provide deeper experiments; [standalone lab drafts](../labs/README.md) provide unfinished learner functions. No PortOps lab variant is currently distributed.
